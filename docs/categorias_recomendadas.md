# Campos do sistema
Para cada empresa, sugiro armazenar:

-categoria_principal: uma única categoria, como “Saúde”.
-subcategoria: uma única subcategoria, como “Odontologia”.
-categorias_secundarias: até 2 ou 3 categorias adicionais, para empresas híbridas.
-tags: termos livres, como “implante dentário”, “delivery”, “atendimento 24h”.
-publico_alvo: consumidor final, empresas, rural, B2B, B2C.
-raio_de_atendimento: bairro, Barretos, região.
-status: ativo, inativo, pendente de validação.
