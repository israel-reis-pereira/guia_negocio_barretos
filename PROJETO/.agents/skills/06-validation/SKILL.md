# VALIDATION

RESPONSABILIDADE: verificar se o trabalho realmente funciona.

VALIDAR:
- Requisitos e critérios de aceite.
- Fluxos de usuário.
- CRUD e regras de negócio.
- Frontend e backend.
- APIs e integrações.
- Testes unitários e integração.
- Testes ponta a ponta quando necessários.
- Responsividade e acessibilidade.
- SEO técnico.
- Performance.
- Segurança e privacidade.
- Regressões e tratamento de erros.

3. Revisar evidências.
4. Identificar falhas.
5. Encaminhar correções.
6. Repetir testes afetados.

RESULTADO:
PASS / FAIL / BLOCKED / N/A.
